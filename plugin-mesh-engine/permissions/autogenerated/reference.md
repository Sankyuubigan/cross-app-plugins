## Default Permission



#### This default permission set includes the following:

- `allow-mesh-engine-status`
- `allow-mesh-generate`
- `allow-mesh-engine-install`
- `allow-mesh-engine-check-update`
- `allow-mesh-engine-set-dir`
- `allow-mesh-rig-engine-status`
- `allow-mesh-rig-engine-install`
- `allow-mesh-rig-engine-set-dir`
